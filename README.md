# 🌸 Women's Empowerment Website

A beautiful, interactive website celebrating women's achievements, empowerment, and contributions to society. Built with modern web technologies to create an engaging experience that honors and inspires.

## ✨ Features

### 🎯 Interactive Components
- **Hero Section** - Eye-catching landing with powerful messaging
- **Inspirational Women** - Profiles of iconic women who changed history
- **Timeline** - Historical milestones in women's rights and achievements
- **Women in Different Fields** - Showcasing contributions across various domains
- **Appreciation Wall** - Community space to share gratitude and appreciation
- **Quote Generator** - Inspiring quotes from influential women
- **Women's Quiz** - Test your knowledge about women's history
- **Memory Game** - Fun, educational card matching game
- **Gallery** - Visual celebration of women's achievements
- **Thank You Cards** - Create and share personalized appreciation cards
- **Gratitude Counter** - Track collective appreciation

### 🎨 Design & UX
- Fully responsive design for all devices
- Modern UI with shadcn/ui components
- Smooth animations and transitions
- Accessible and user-friendly interface
- Confetti celebrations for interactive moments

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui (Radix UI primitives)
- **Routing**: React Router v6
- **State Management**: TanStack Query (React Query)
- **Form Handling**: React Hook Form with Zod validation
- **Icons**: Lucide React
- **Animations**: Tailwind CSS Animate
- **Testing**: Vitest + React Testing Library

## 📦 Installation

### Prerequisites
- Node.js (v16 or higher)
- npm or bun package manager

### Setup

```sh
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd <project-name>

# Install dependencies
npm install
# or
bun install

# Start development server
npm run dev
# or
bun dev
```

The application will be available at `http://localhost:5173`
